# Support

## Questions and usage help

Open a [GitHub Discussion](https://github.com/orgs/codasaurus-oss/discussions)
or an issue in the relevant repository. Include the version, deployment method
(Docker, binary, host), and the relevant log lines.

## Bug reports

Use the bug report template in the repository where the problem occurs. A
minimal reproduction is the fastest path to a fix.

## Security issues

Do not open a public issue. See [SECURITY.md](SECURITY.md) and email
**iam@thelohit.in**.

## What is not supported

- Custom patches applied to released artifacts
- Third-party forks
- Private deployment debugging without logs or a reproduction
